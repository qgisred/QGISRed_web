Nova Ferramenta para Alterar o Estado dos Elementos e Simbolização conforme seu Estado

Uma das operações mais habituais na hora de modificar um cenário de simulação é alterar o estado de algum elemento da rede, seja de regulação ou não, passando de aberto para fechado ou vice-versa.

Para facilitar essa tarefa, o QGISRed incorpora uma ferramenta específica que altera o estado dos elementos ao tocar sobre eles, sem a necessidade de abrir o Editor de Propriedades para modificá-lo. Além disso, agora todos os elementos têm uma cor em função de seu estado, que muda ao modificá-lo, incluindo o traço no caso das tubulações fechadas. A ferramenta também é aplicável às ligações de serviço e válvulas de isolamento. No caso das válvulas de regulação, estas passam pelos três estados possíveis em um rodízio rotativo.
