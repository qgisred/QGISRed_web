QGIS Plugin

An integrated working platform

QGISRed is not a set of isolated tools: it is a working platform that allows you to import models, edit layouts, declare element properties, build calculation scenarios and analyse results within a single GIS environment.

It harnesses the power of QGIS to georeference elements, overlay cartographic backgrounds and perform geoprocessing, all while building and calibrating your hydraulic model.
