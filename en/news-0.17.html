Version 0.17 updates Latest

February 2026 · The most important improvements in this version

More than 3 years have passed since the last official QGISRed version. Version 0.17 gathers the most important advances. Many features were already anticipated in beta versions up to 0.16.13, released through GitHub to address incompatibilities with newer QGIS 3.4x versions.

1. New isolated segment identification tool

One of the most requested features in water distribution network simulation software is the automatic determination of which valves must be closed to isolate a segment around a damaged or maintenance element.

The new tool automatically calculates the minimum segment isolated when closing a given set of valves, showing affected elements and the number of customers without service.

2. Identification of up to 13 states in pipes, pumps and valves

The initial status of a transport element (pipe, pump, valve) declared in EPANET can be open or closed. However, the calculation result can reveal up to 13 distinct states depending on the element type and hydraulic conditions. QGISRed now identifies and symbolises all of them.

3. Successive simulation chaining

As more real data becomes available, the opportunity arises to match the model to reality over longer periods. Simulation chaining runs multiple consecutive simulation periods, using the final state of each as the initial condition for the next.

4. EPANET-compatible scenario management

EPANET provides an option to export/import scenarios — pipe diameters, roughness, node demands, initial quality, etc. QGISRed 0.17 integrates this functionality, allowing scenarios to be managed in a format fully compatible with native EPANET.

5. New Project Manager options

The QGISRed Project Manager is one of the most used tools, easily switching between scenarios. This version adds new options to improve the organisation and management of complex projects with multiple scenarios.

6. EPANET Toolkit 2.3 integration

QGISRed 0.17 integrates version 2.3 of the EPANET Toolkit, which includes bug fixes, performance improvements and new analysis options over the previous version 2.2.

7. Minor improvements and bug fixes

Version 0.17 also continues to refine features already offered by QGISRed. For full details of all minor improvements and corrections, see the version history.
