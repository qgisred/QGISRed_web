Open source

Issues

QGISRed issues are managed through GitHub's issue tracker. GitHub registration is required to participate actively.

  • Issues are divided into Open and Closed categories with coloured labels
  • You can follow conversation threads and add new messages
  • Use the green New Issue button to create a new issue
  • Describe: QGIS version, QGISRed version and steps to reproduce

Paid service

Technical Support

We offer personalised technical support with priority response through an annual subscription.

  • Faster response times than public forums
  • Distance-based assistance: email, video conference and remote access
  • Guidance on problem-solving approaches
Technical support does not include client data analysis, network model development or custom feature development.
