What is QGISRed?

QGISRed is a QGIS plugin designed to facilitate the construction and analysis of hydraulic models of water distribution networks. The tool enables users to build hydraulic models ranging from simple schemas to sophisticated digital twins.

As a free plugin, it leverages GIS capabilities for georeferencing network elements, overlaying geographic backgrounds, editing graphic and alphanumeric data, and performing geoprocessing operations. The platform is an integrated working environment — not isolated tools — allowing users to import models, edit layouts, declare element properties, build calculation scenarios, and analyse results within one environment.

History

Background

The origins trace back to 2004, when researcher Fernando Martínez directed the development of GISRed, a predecessor tool using the Avenue language for ArcView 3.2. Although early versions supported major water supply projects (including Valencia's 1.5 million-person metropolitan area), technological obsolescence limited adoption.

Following fifteen years without comparable open-source alternatives, and with EPANET's code liberation in 2015, the team decided to reimagine GISRed within QGIS. The first public presentation took place at the CCWI 2019 Conference in Exeter, UK.

Applications

QGISRed supports three main types of network models

Static Models

Pipeline dimensioning, network planning, model calibration, failure simulation, criticality analysis, network sectorization, and energy audits.

  • Pipeline dimensioning
  • Network planning
  • Model calibration
  • Failure simulation
  • Criticality analysis
  • Network sectorization
  • Energy audits

Dynamic Models

Regulation control optimisation, extended-period calibration, reliability analysis, maintenance scheduling, and demand management.

  • Control optimisation
  • Extended-period calibration
  • Reliability analysis
  • Maintenance scheduling
  • Energy consumption reduction
  • Water quality monitoring
  • Demand management & leak detection

Digital Twins

Real-time data integration, continuous model calibration, unmeasured value inference, anomaly detection and operational optimisation.

  • Real-time data integration
  • Continuous model calibration
  • Unmeasured value inference
  • Anomaly detection
  • Predictive capabilities
  • Operational optimisation
Getting started

Installation

QGISRed requires QGIS to be installed first (version 3.2 or later). Currently runs on Windows only.

  1. Download and install QGIS from qgis.org
  2. Open QGIS and go to Plugins → Manage and Install Plugins
  3. Search for "QGISRed" and click Install
  4. On first use, required libraries download automatically within seconds
Install from QGIS Plugin Manager
Open source

GitHub Project

The Python interface code of the plugin is publicly accessible on GitHub under GNU GPL 2.0 licence. The repository hosts the code managing QGIS interface customisation and network element editing capabilities.

The core computational algorithms — containing most of the processing logic — are developed in C# within proprietary DLL libraries, using the EPANET 2.2 Toolkit and Shapefile libraries.
