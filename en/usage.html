User Manual

The QGISRed user manual documents all application capabilities in detail. Available in Spanish and English, it is updated with each new version.

The manual is written in Word format and distributed as PDF. It includes a brief tutorial for running the example file Red1_SI.inp and the steps to build a project from scratch.

Examples

Red1_SI.inp

International System of Units

A simple example demonstrating chlorine decay, including reaction coefficients in the bulk fluid and at the pipe walls. All units are expressed in SI. Includes a regulation valve configurable in different modes.
