Isolated segment identification

Featured capability · v0.17

What is an isolated segment?

A segment is the minimum network unit that can be completely isolated from the supply by closing a set of isolation valves. The concept is fundamental to operational management: in the event of a fault or pipe burst, the operator needs to know which valves to close to isolate only the affected section, minimising supply interruption.

QGISRed's isolated segments tool (introduced in v0.17) automatically calculates all network segments based on the position of existing isolation valves.

Optimal isolation calculation

For an incident on a specific element, the tool calculates:

  • Valves to close: the minimum set of isolation valves needed to isolate the segment containing the affected element
  • Affected segment: all pipe sections that lose supply when those valves are closed
  • Affected consumers: number of connections and total demand that loses supply
  • Inoperative valves: detects valves that due to their position do not allow complete isolation (poorly delimited segments)

Applications in operational management

The isolated segments tool has multiple practical applications:

  • Emergency protocols: document the isolation procedure for each critical section
  • Maintenance planning: calculate the supply impact before scheduling an intervention
  • Segmentation improvement: identify network areas with excessively large segments requiring new valves
  • Digital Twin integration: by closing valves in the model, hydraulically simulate the isolation scenario
Prerequisite: For accurate results, the isolation valve layer must be complete and correctly georeferenced on the network. The tool can be run in diagnostic mode to assess current valve coverage before a complete inventory is available.
