Enhanced Property Editor

Featured capability · Efficient editing

What is the Property Editor?

The QGISRed Property Editor is the central panel for reviewing and modifying the attributes of all network elements: pipes, nodes, tanks, pumps, valves and reservoirs. It is the alternative to opening QGIS's attribute table element by element.

The editor displays the attributes of the element selected on the map and allows direct editing with immediate validation of the values entered.

Navigation between linked elements

One of the editor's most valued improvements is the ability to navigate directly between related elements without returning to the map:

  • From a pipe: access the end nodes directly
  • From a node: view all connected pipes
  • From a pump: access the associated characteristic curve
  • From a valve: view upstream and downstream nodes

This navigation allows the network topology to be inspected quickly and efficiently without relying on the map view.

Editing without layer pre-selection

In standard QGIS, to select and edit an element you need to have the corresponding layer active in the layers panel. In complex networks with multiple overlapping layers, this considerably slows down the workflow.

The QGISRed Property Editor removes this restriction: simply click on any network element on the map and the editor automatically identifies it, regardless of which layer is active. The editor detects the element type and loads its properties immediately.

Multi-element editing

The editor also supports editing attributes across multiple elements simultaneously:

  • Rectangular or polygon selection on the map
  • Modifying one attribute across all selected elements
  • Filtering by element type within the selection
