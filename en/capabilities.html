Support for pressure-dependent demands (PDA) versus the classic fixed demand (DDA) approach, bringing the model closer to system reality.

Current Features

QGISRed has been in continuous development for over four years. These are its main capabilities.

Project Management

  • Project manager for loading and saving projects
  • Automatic creation of empty project or from INP file
  • Project cloning and backup
  • Project metadata and options management

Graphical Editing Tools

  • Automatic node creation when drawing pipes
  • Automatic topological relationship creation
  • Insert valves and pumps as linear elements or at nodes
  • Create, delete, move and edit network layout
  • Automatic layout reversal
  • Change status of pipes, pumps and valves

Property Editing

  • Specific windows for editing element properties
  • Element search by type and ID
  • Navigator to visit linked elements
  • Multi-element selection by region
  • Multiple demands as independent layer
  • Emitters and contaminant sources recognition

Data Completion Assistants

  • Automatic pipe length recalculation by CRS
  • Automatic node elevation interpolation from DEM
  • Pipe roughness estimation and conversion
  • Automatic demand assignment from sectoral data
  • Modulation curve assignment
  • Pattern, curve and control rule editors

Import and Export

  • Import from EPANET INP files
  • Export to INP files
  • Import from GIS layers (SHP, GPKG)
  • Export results to GIS layers
  • Import from corporate GIS databases

Verification and Debugging

  • Network topology verification
  • Disconnected element detection
  • Duplicate pipe identification
  • Data completeness check
  • Error and warning report

Scenario Management

  • Scenario builder
  • Multi-scenario project manager
  • Compatibility with EPANET-exported scenarios
  • Successive simulation chaining

Results Visualisation

  • Results represented as GIS layers
  • Up to 13 states identified in pipes, pumps and valves
  • Extended-period results animation
  • Export results to tables and charts
