Manual del Usuario

El manual del usuario de QGISRed documenta en detalle todas las capacidades de la aplicación. Está disponible en español e inglés y se actualiza con cada nueva versión.

El manual está escrito en Word y se distribuye en PDF. Incluye un tutorial breve para ejecutar el fichero de ejemplo Red1_SI.inp y los pasos para construir un proyecto desde cero.

Ejemplos

Red1_SI.inp

Sistema Internacional de Unidades

Se trata de un ejemplo sencillo para mostrar el decaimiento del cloro. Incluye coeficientes de reacción en el medio y en las paredes. Todas las unidades están expresadas en SI. Incluye una válvula de regulación configurable en diferentes modos.

Este ejemplo está referenciado en el manual del usuario y sirve como base para el tutorial introductorio.
